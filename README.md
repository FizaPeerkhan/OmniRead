# OmniRead

**Complexity Stripped. Clarity Delivered.**

An NLP-powered reading assistant designed to improve reading accessibility by simplifying complex text, highlighting difficult vocabulary, providing contextual explanations, and supporting users with dyslexia and other reading difficulties.

## Tech Stack

- Python
- FastAPI
- React
- spaCy
- Hugging Face Transformers

## Project Structure

- `backend/` - Backend APIs and NLP services
- `frontend/` - React application
- `datasets/` - Raw and processed datasets
- `notebooks/` - Research and experimentation
- `docs/` - Proposal, architecture, and report
